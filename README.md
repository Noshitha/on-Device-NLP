# Project Branch Overview

This repository is organized into several branches,we seek out to develop on-device translation model. 

## Branch Structure

- **sudhanshu**:  
  This branch is dedicated to developing compression techniques. All experimental work related to model optimization is being actively developed here.

- **sudhanshu_baseline**:  
  This branch serves as the baseline for testing. 

- **main**:  
  Please ignore this branch for now. The main branch is not actively maintained during this phase of development.

## How to Use

- For **development** of new techniques, checkout the `sudhanshu` branch.
- For **baseline evaluation**, use the `sudhanshu_baseline` branch.
- Updates to the main branch will resume once the current experimental phase is completed.
